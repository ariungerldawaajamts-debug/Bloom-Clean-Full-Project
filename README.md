# Bloom — Flowers & Coffee

## VS Code дээр ажиллуулах
1. Энэ folder-ийг VS Code-оор нээнэ.
2. Terminal дээр `npm install` ажиллуулна.
3. Дараа нь `npm start` ажиллуулна.
4. Browser дээр `http://localhost:5000` нээнэ.

HTML partial хэсгүүд `fetch` ашиглан ачаалагддаг тул `file://` горимд ажиллахгүй. `npm start` хийж localhost:5000 дээр нээх.

## Admin нэвтрэх
Энгийн хэрэглэгч Admin хэсгийг харах болон захиалгын статус өөрчлөх эрхгүй.

Demo Admin:
- И-мэйл: `admin@bloom.mn`

Хэрэглэгчийн бүртгэлээр орсон үед зөвхөн хэрэглэгчийн хэсгүүд ажиллана.

## Анхаарах зүйл
Энэ хувилбар нь сургалтын/demo зориулалттай client-side role хамгаалалттай.
 Жинхэнэ production системд хэрэглэгчийн нууц үг, admin эрх, захиалгын статусыг server/database дээр шалгах шаардлагатай.

Нууц үг сэргээх одоогоор demo горимд ажиллана: имэйл илгээхгүй, зөвхөн энэ төхөөрөмжийн `localStorage` дахь хэрэглэгчийн demo нууц үгийг өөрчилнө. Бодит сэргээхэд сервер дээр `POST /api/auth/password-reset` болон `POST /api/auth/password-reset/confirm` endpoint, нэг удаагийн хугацаатай token үүсгэх/баталгаажуулах/хэрэглэсний дараа хүчингүй болгох, нууц үгийг сервер талд хамгаалалттай хадгалах, имэйл илгээх үйлчилгээ шаардлагатай. Frontend token хадгалахгүй. Backend-ээр ажиллуулах үед хуудсыг ачаалахаас өмнө `window.BLOOM_PASSWORD_RESET_API = true` тохируулж болно.

## QPay
QPay backend-ийн бүтэц `server.js` дотор бэлэн. 
Бодит QPay merchant credentials болон webhook тохиргоо шаардлагатай.
Банкны QR гараар баталгаажуулах нь localStorage demo тул хэн ч төлвийг өөрчилж чадна; бодит ашиглалтад захиалгыг серверт хадгалж, админы эрхийг серверээр шалгах шаардлагатай.
