# Bloom — Flowers & Coffee

## VS Code дээр ажиллуулах
1. Энэ folder-ийг VS Code-оор нээнэ.
2. Terminal дээр `npm install` ажиллуулна.
3. Дараа нь `npm start` ажиллуулна.
4. Browser дээр `http://localhost:5000` нээнэ.

## Admin нэвтрэх
Энгийн хэрэглэгч Admin хэсгийг харах болон захиалгын статус өөрчлөх эрхгүй.

Demo Admin:
- И-мэйл: `admin@bloom.mn`
- Нууц үг: `BloomAdmin123!`

Хэрэглэгчийн бүртгэлээр орсон үед зөвхөн хэрэглэгчийн хэсгүүд ажиллана.

## Анхаарах зүйл
Энэ хувилбар нь сургалтын/demo зориулалттай client-side role хамгаалалттай.
 Жинхэнэ production системд хэрэглэгчийн нууц үг, admin эрх, захиалгын статусыг server/database дээр шалгах шаардлагатай.

## QPay
QPay backend-ийн бүтэц `server.js` дотор бэлэн. 
Бодит QPay merchant credentials болон webhook тохиргоо шаардлагатай.
